# Frequently asked questions

### What does a Tally TCP decompiler do?
It reads a compiled Tally customization (`.tcp`) and reconstructs readable TDL definitions where the file layout is supported.

### Which TCP formats are supported?
Regular, Inscribed V1 and Inscribed V2 layouts are recognized. Results depend on the structure and obfuscation of each file, and support for every TCP is not guaranteed.

### Can I decompile a TCP file for free?
Yes, for Regular TCP files strictly below 5 KB through the Community plan. Larger or Inscribed files use a paid option, and you see the exact price before processing.

### Will I be charged if recovery fails?
On the Single File plan, a failed recovery is not charged.

### Will the recovered TDL match the original?
Not exactly. Formatting, comments and names can differ, and obfuscated identifiers may remain.

### Can I convert TCP to text?
Yes. You can download the recovered output as a text file or as a `.tdl` file.

### Are my files private?
Recovered results are saved in your private library in your account. See the website for the current privacy details.

### Do I pay again to reopen a saved result?
No. Saved results can be reopened without another charge.

### Is this affiliated with Tally Solutions?
No. It is an independent service.

### My file is large or unsupported. What now?
Contact the team via [Telegram](https://t.me/softssrvs) to discuss a custom project.
