# TCP Decompiler: Tally TCP to TDL / Text

**Website: [https://tcpdecompiler.in](https://tcpdecompiler.in)**

TCP Decompiler is an online tool for Tally developers and consultants. It helps you recover readable **TDL (Tally Definition Language)** source from compiled Tally **TCP** files, so you can review the logic of a customization and keep working on it.

If you are searching for a **TCP decompiler**, a **TCP to TDL converter**, a **TCP to text** tool, or a way to **decompile Tally TDL**, this project is for you.

> This repository is the project's public information page and documentation. The decompiler itself runs on the website, not in this repository.

---

## What you can do

- Convert a Tally `.tcp` file into readable `.tdl` or `.txt` output
- Recover definitions such as reports, forms, parts, lines, fields, functions and variables where the file layout is supported
- Work with Regular and Inscribed (V1 / V2) TCP layouts
- Simplify long alias chains to make recovered formulas easier to read
- Keep recovered files in a private library and reopen them later

## How to use it

1. Open **[tcpdecompiler.in](https://tcpdecompiler.in)** and create a free account.
2. Upload your `.tcp` file.
3. The server detects the file layout and reconstructs the TDL.
4. Copy the result, or download it as a TDL or text file.
5. Test the recovered code in a separate Tally environment before using it for real work.

## Important notes

- Recovered source may differ from the original in formatting, comments and names.
- Obfuscated identifiers can remain in the output, and some definitions may need manual adjustment.
- Support for every TCP file is not guaranteed.
- Only decompile files you own or have permission to work on.
